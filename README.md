# ⚡ Карта энергии

**Отмечайте бодрость — тепловая карта покажет часы пика и спада, а подсказки — что заряжает.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/energy-map/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Отметка в одно касание с тегами (кофе, спорт, сон…)
- Тепловая карта «день недели × час»
- График энергии за сегодня
- Автоматические выводы: пик, спад, влияние тегов
- Пример данных на три недели

## Стек

JavaScript, SVG. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/energy-map.git
cd energy-map
python3 -m http.server 8000
```
